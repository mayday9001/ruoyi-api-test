## 二、Docker 安装过程

### 步骤

1. 下载 Docker Desktop for Windows（**AMD64** 版本）
2. 安装时配置项：
   - ✅ Per-user installation (Recommended)
   - ✅ **WSL 2**（后端）
   - ✅ Add shortcut to desktop
3. `Installing files…` → `Installation succeeded`
4. 首次启动：接受 Docker Subscription Service Agreement（个人学习免费）
5. 登录页选择 **Skip**（无需 Docker Hub 账号）
6. 主界面左下角显示 **`Engine running`**

### 验证命令

```powershell
docker --version
docker info
docker run --rm docker.1ms.run/library/hello-world
```

**验证输出**：

```
Hello from Docker!
This message shows that your installation appears to be working correctly.
```

✅ 说明 Docker 客户端 → 守护进程 → 镜像拉取 → 容器运行 全链路正常。

## 三、踩坑记录（重点）

### 坑 1：Docker Hub 直连超时

**现象**：

```powershell
docker run -d -p 3000:3000 --name booker mwinteringham/restful-booker

docker: Error response from daemon: failed to resolve reference
"docker.io/mwinteringham/restful-booker:latest":
dial tcp [2a03:...]:443: connectex: A connection attempt failed because
the connected party did not properly respond after a period of time...
```

**原因**：无法访问 `registry-1.docker.io`（国内网络常见）。

**排查结论**：`docker.1ms.run`、`docker.m.daocloud.io` 两个镜像站本身可达（访问 `/v2/` 返回 `401 UNAUTHORIZED`，这是正常的鉴权响应）。

### 坑 2：目标镜像在镜像站不可用

| 尝试 | 结果 |
|---|---|
| `mwinteringham/restful-booker`（直连 Hub） | ❌ 连接超时 |
| `docker.1ms.run/mwinteringham/restful-booker` | ❌ `not found` |
| `docker.m.daocloud.io/mwinteringham/restful-booker` | ❌ **"这镜像不在白名单"** |
| `docker.1ms.run/library/hello-world` | ✅ **成功** |

**结论**：Docker 环境本身没问题，是该镜像不在国内镜像站白名单内。

### 解决方案（止损）

**不为一个镜像耗时间。** 换被测系统：

- 原计划：`restful-booker`（需 Docker 部署）
- 改用：**`https://api.restful-api.dev`**（公开在线 API，零部署）

**经验总结**：
> 测试框架的能力（分层、数据驱动、断言、报告、CI）**与被测系统无关**。
> 遇到环境问题要设止损线（如 1 小时），到点就换备选方案，把时间留给框架本身。

### 镜像拉取的正确姿势（本项目通用）

```powershell
# 官方镜像：加 library/ 前缀
docker pull docker.1ms.run/library/mysql:8
docker pull docker.1ms.run/library/redis:7

# 第三方镜像：直接加前缀
docker pull docker.1ms.run/<用户名>/<镜像名>
```

## 五、Postman 配置记录

### Environment 变量

| Variable | Value |
|---|---|
| `baseUrl` | `https://api.restful-api.dev` |
| `objectId` | `3` |

> **踩坑提醒**：Postman 新版 Environment 表格是 **2 列**（Variable / Value），
> 老版是 3 列（Variable / Initial value / Current value）。
> 新版只需要填「变量名 + 值」，不要把那两个列名当成变量名填进去。

### 首个请求验证

```
GET {{baseUrl}}/objects
→ 200 OK，1.3 KB，13 条数据
```

### Tests 断言（3 条全部 PASSED）

```javascript
pm.test("状态码 200", () => pm.response.to.have.status(200));
pm.test("返回数组", () => pm.response.json()).to.be.an("array"));
pm.test("至少 13 条", () => pm.response.json().length).to.be.at.least(13));
```
